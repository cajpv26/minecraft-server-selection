## MC 吃单核，不看核数堆料

Java 版服务端的主逻辑跑在主线程上，1.18 之后的高版本把单核需求拉得更高。你拿一台 2.9GHz 的老至强去开模组服，TPS 掉到 15 不算意外，而这时候 CPU 占用率可能还没满，因为核多没用。

雨云官方论坛那篇 2026 年 8 月的开服教程给的标准可以直接拿来用：**选 CPU-Z 单核跑分 600 以上的机型**，14900K、13900K、7950X、9950X 属于久经验证的选择；**内存 4 核 8G 是比较推荐的起步配置**，低于这个不是跑不动，玩家一多、再叠 MOD 和插件，体验就会掉。

第三方整理把在售机型按单核性能分了档，用来对照自己的玩法够不够：

- **i9-14900K / 14900KF（6.0GHz）**：CPU-Z 单核 880 到 900 分，1.20+ 大型模组整合包、50 人起步群组服
- **Ryzen 7950X / 9950X（5.7GHz）**：Zen5 架构，单核紧咬 i9，Linux 下甚至反超，高版本插件加模组混开性价比更高
- **R9 5900X（4.8GHz）**：单核 450 到 520 分，中高版本模组服、小型群组服、基岩版轻量服的均衡档
- **Gold 6146（4.2GHz）**：纯净插件服够用
- **Platinum 8275cl / 8259cl（3.9GHz）**：多核强、单核弱，低版本模组或高版本纯净插件可以，有免费兑换套餐
- **E5 2666v3（2.9GHz）**：单核最弱，只建议超低预算挂机服和低版本小型生存，同样有免费档

整理者的结论是一句话：1.18+ 模组服优先 i9 或 Ryzen 7000 系，低预算或老版本再考虑至强系列。

## 面板套餐和 VPS 裸机，第一次开服选哪个

**第一次开服从面板套餐入手。** MCSM 面板把开服流程压缩成"选服务端类型（Paper、Forge 等）→ 设端口 → 一键启动"这几步，在线改配置文件、上传整合包、看控制台输出都在网页上完成。面板套餐还支持 CPU 升降级、自动备份、自带 MySQL，后期人多了拖滑块加内存就行，不用重装系统搬家。

面板套餐的边界也要知道。按论坛较早一篇教程的说法，MCSM 模式不适合开群组服、也不方便挂机器人框架，扩展性比裸机低。你如果打算做多服联动的群组架构，或者要装需要碰系统层的插件，这档就不合适。

**VPS 裸机自由度高，门槛也高。** 要自己在 SSH 里换软件源、装 JDK、传 server.jar、写启动命令，出问题自己排查。适合已经开过服、明确知道自己要装什么的人。它和面板套餐在价格上的差距，前面表格已经摆出来了。

## 开服路上真正会卡住的四个地方

这几步和买哪档机型无关，几乎每个人都会碰到，提前知道能省一晚上。

**1. Java 版本对不上，服务端直接起不来。** 对照关系是：JDK 8 对应 1.7 及以下，JDK 11 对应 1.8 到 1.16，JDK 17 对应 1.17 到 1.19，JDK 21 对应 1.20 及以上。开 1.20 以后的版本却装了 JDK 8，报错信息不会告诉你"版本错了"，只会给你一堆看不懂的异常。装之前先确认自己要开的版本。

**2. EULA 没同意。** 第一次启动大概率看到 `You need to agree to the EULA in order to run the server. Go to eula.txt for more info.`，进文件管理把 `eula.txt` 里的值从否改成是，保存再启动。

**3. Docker 容器端口没开。** 用面板的 Docker 镜像创建实例后，要在"容器化 → 开放端口 → 新增配置"里把主机端口和容器端口都填 `25565`，协议选 TCP。只填一边，服务端在容器里跑得好好的，外面就是连不上。

**4. NAT 共享 IP 要自己映射端口。** 便宜机型走的是 NAT 共享公网 IP，需要在控制台的"端口映射"里手动加规则：MCSM 面板要 23333 和 24444 两个端口，Minecraft 服务端要 25565，协议选 TCP+UDP，外网端口用系统给的随机值就行，范围在 10000 到 60000 之间，提示被占用就换一个。

另外两个小坑。客户端连接要写成 `IP:端口` 的格式，冒号用英文的，端口填 25565 映射出来的公网端口，写成中文冒号连不上；`server.properties` 里的 `online-mode` 改成否可以让没有正版账号的朋友进服，代价是谁都能进，被 ban 了换个 ID 还能回来搞破坏，私人小服图省事可以这么干，半公开的服别关。

给 OP 权限在 MCSM 终端里敲 `op 玩家ID` 就行。进不去游戏时先查两件事：内网端口填对没有，外网端口是不是被别的服务占了。

## 机房怎么选：延迟和独立 IP 的取舍

**江苏镇江**走 NAT 网络，多个用户共用一个公网 IP，提供 15 个端口转发，纯 MC 服够用，想独占公网 IP 可以加钱升级独立 IP 版。

**镇江和宿迁都是 BGP 线路**，电信、联通、移动的用户延迟都比较低，玩家来自五湖四海时优先这两个。

**浙江宁波**有便宜的独立公网 IP，但是电信单线，高峰期其他运营商的玩家延迟会明显变高。如果你的朋友全是电信宽带，这条线没问题；只要有一个用移动或联通，慎重。

**宿迁高防**那几档配的是高防线路，带 150G 共享 DDoS 防御。小服一般用不上，被恶意打过一次就知道值不值。

计费模式上还有个选择。动态计费在 CPU 占用率超过 20% 时额外收费，每天有免费额度，白天没人、晚上才热闹的私人服选它更省；论坛较早一篇教程则推荐固定计费"全程火力全开"，那是 2024 年的观点。现在开新服，先按自己的在线时段判断，别照抄。

## 哪些人不适合选它

- **玩家主要在海外**：雨云的机房以国内为主，海外节点相对少，跨洋延迟不是它的战场
